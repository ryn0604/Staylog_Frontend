# Frontend (숙소 상세 페이지, 리뷰 게시판 댓글, 예약폼 담당)

React + TypeScript + React-Bootstrap 기반의 SPA 형태로 구현했습니다.

### 담당 기능
- 숙소 상세 조회
  - 숙소 기본 정보 조회 (이름, 위치, 설명 등)
  - 숙소 이미지, 가격, 옵션 데이터 제공
  - 숙소별 객실 목록 리스트 표시
  - **반응형 구현** : 모바일, 태블릿, PC 화면에 맞춘 UI 레이아웃 조정
- 리뷰 기능
  - 숙소 리뷰 목록 조회 및 해당 숙소의 전체 리뷰 표시
  - 리뷰 게시판 댓글 작성, 수정, 삭제
  - 댓글 답글 기능 구현
- 예약폼
  - 체크인/체크아웃 날짜 선택
  - 인원 수 선택
  - 객실 옵션 선택
  - 선택 사항에 따른 총 숙박 금액 자동 계산
  - UI와 로직 연동으로 즉시 계산 가능

### 기술 스택
- React + TypeScript  
- React-Bootstrap (Grid와 CSS 활용, 반응형 UI 구현)  
- 모달 및 동적 UI 상태 관리  
- 상태 관리: useState, useEffect 등
